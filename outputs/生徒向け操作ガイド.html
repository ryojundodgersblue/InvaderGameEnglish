🔑ログインする

Google Chrome でゲームのページを開いて、先生からもらった User ID と Password を入力し、LOGIN ボタンを押します。

アクセスするところ → https://invader-game-english.vercel.app/
⏰ だいじ！

ログインボタンを押したあと、1分くらい待つことがあります。
「サーバーを起動しています…」と出ても、こわれていません。そのまま待ってね。ボタンを何度も押さなくてだいじょうぶ！

2

🗺️ステージをえらぶ

Grade（学年）→ Part → Subpart のじゅんにえらんで、Game Start を押します。今までに進んだところまでえらべます。まよったら、最初から出ているステージ（いちばん新しいところ）でOK！

💡 ここでも画面が変わるまですこし時間がかかることがあります。あわてず待ちましょう。
3

🚀ゲームをはじめる

ステージのせつめい（Requirement）を読んで、Start を押します。

さいしょの1問はデモ（見本）です。左に「デモ」と出ている間は、見ているだけでOK。答え方のお手本が自動で流れます。そのあと、本番の問題が 1〜7 のばんごうで出てきます。
